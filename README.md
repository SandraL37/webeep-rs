# WebeepSync-RS

WebeepSync-RS is a rewrite of the Webeep Sync client in Rust. This is a POC able to login and print the user's `firstname` and `lastname`.

# How to run

Go check [prerequisites](https://v2.tauri.app/start/prerequisites/) to run tauri.
And then:

```bash
git clone https://github.com/SandraL37/webeep-rs.git
cd webeep-rs

pnpm install
pnpm tauri dev
```

You can use whatever package manager you prefer.
